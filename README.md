JavaScript | Command-Line Interface (CLI)

> A Node.js inventory management system that runs in the terminal and supports complete CRUD operations.

---

## Features

- List all products in inventory
- Add new products
- Remove existing products
- Edit product name, price, or quantity
- Search and filter products
